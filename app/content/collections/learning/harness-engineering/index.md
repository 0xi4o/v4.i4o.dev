How AI agent harnesses work, learned by building one in Go: a provider layer
that puts many LLM APIs behind one set of types, and an agent core that runs
the loop, the tools and the events. pi's `pi-ai` and `pi-agent-core` are the
reference implementation, read at a pinned commit.
