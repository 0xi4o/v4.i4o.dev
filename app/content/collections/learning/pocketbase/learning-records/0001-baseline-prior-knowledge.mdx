# Baseline — experienced full-stack dev, zero PocketBase

Ilango is a professional full-stack engineer who writes Go daily (Ink, an SSG)
and React on the frontend. He has never run PocketBase and has not used
Firebase/Supabase-style BaaS tools either — the backend-as-a-service mental
model itself is new, not just this tool.

## Implications

- Never teach Go, SQL, HTTP, or React — reference them freely as known ground.
- Do teach BaaS concepts explicitly (collections vs tables, rules vs middleware
  auth, admin UI as schema editor) — no prior BaaS intuition to lean on.
- The zone of proximal development starts at "what PocketBase is and how it
  thinks", not at "what a REST API is".
