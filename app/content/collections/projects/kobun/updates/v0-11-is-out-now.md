This release adds an important feature that I need for my own use but will also be beneficial to how you write and publish content — subcollections!

## What are subcollections?

So far we’ve only had one top level of collections. Now you can create collections within collections. Here are some use cases:

- Series — articles that are about a single topic that can be grouped together
- Projects — each project can now have a list of updates, changelogs, etc
- Documentation — Guides and API References can now coexist under a parent Documentation collection without having to create two separate ones
